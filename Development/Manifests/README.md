# Historical source package manifest

`SOURCE_PACKAGE_MANIFEST.txt` is retained here as the SHA-256 inventory of the imported source-package snapshot.

It is a historical baseline, **not** a current-tree verification manifest. Subsequent repository work consolidated release notes, relocated stage guides and test evidence, and added development sources; therefore some path names and hashes in this snapshot no longer match the current repository tree. Do not use it as a current checkout integrity check. Generate a fresh manifest from a specific commit when one is required.
